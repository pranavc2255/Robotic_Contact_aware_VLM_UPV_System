# Compact Windows bundle

Historical 63-trial source record. The main result now uses `trials72.csv` and
the CLIP ensemble documented in `../../docs/CLIP_ENSEMBLE.md`. This historical
description is retained for provenance, not as the current default result.

This bundle contains the saved artifacts used for the 90.48% result (57/63).
All files were renamed to short identifiers to avoid Windows path-length limits.
Use FILE_MAP.csv to map each new file to its original repository path.

Areas:
- original27: original 27-trial artifacts, scores, masks, crops, prompts/configs, and labels.
- revision36: 36 revision-trial artifacts, original-prompt CLIP scores, and labels.
- final63: final no-margin labels, combined CSV, and summary.

No repository source code is included.
